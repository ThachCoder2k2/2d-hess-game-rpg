# AN.3 Spec - Boss Animation Plans

**Status:** draft for owner review  
**Linked lane:** Animation  
**Checklist gate:** `AN.3`

## Purpose

Boss animation must communicate phase changes, threat identity, and punish
windows.

## Required Boss Animation Planning

Each boss needs:

- idle authority pose,
- attack windups by pattern,
- phase transition animation,
- hurt/recover state,
- defeat state,
- arena interaction motion if relevant.

## Completion Requirements

`AN.3` can be approved only if:

- every boss has planned tells,
- phase changes are visible,
- and boss animation supports mechanics already specified.

## Cannot Approve If

- phase changes are only HUD/HP changes,
- boss attacks share identical tells,
- or animation obscures danger cells.
