# NAR.3 Spec - Child Voice Rules

**Status:** draft for owner review  
**Linked lane:** Narrative And Worldbuilding  
**Checklist gate:** `NAR.3`

## Purpose

The child should feel present, kind, imaginative, and imperfect.

## Voice Rules

- short lines,
- curious rather than commanding,
- emotional before instructional,
- avoids explaining every mechanic,
- sometimes scared or unsure,
- never sounds like a system narrator.

## Completion Requirements

`NAR.3` can be approved only if the child's voice supports companionship without
interrupting gameplay.

## Cannot Approve If

- child lines become tutorial spam,
- the child sounds all-powerful,
- or the tone becomes sarcastic/parody.
