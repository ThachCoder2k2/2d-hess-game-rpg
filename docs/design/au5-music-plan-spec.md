# AU.5 Spec - Music Plan

**Status:** draft for owner review  
**Linked lane:** Audio  
**Checklist gate:** `AU.5`

## Purpose

Music should support pacing across the two-hour arc without hiding gameplay
warnings.

## Required Music States

| State | Direction |
|---|---|
| Opening aftermath | quiet, fragile, sparse |
| Hub | warm, curious, safe tension |
| District exploration | material-themed light rhythm |
| Combat | small percussion and pulse, not too dense |
| Boss | stronger motif, clear warning space |
| Final King | dark rule-engine tension |
| Ending | gentle release, bedroom morning |

## Completion Requirements

`AU.5` can be approved only if music supports mood and leaves space for
telegraph SFX.

## Cannot Approve If

- music is constant high intensity,
- boss music hides warnings,
- or districts lack identity.
