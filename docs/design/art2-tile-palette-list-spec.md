# ART.2 Spec - Tile Palette List

**Status:** draft for owner review  
**Linked lane:** Art Direction  
**Checklist gate:** `ART.2`

## Purpose

Define the required tile categories before producing or replacing map art.

## Shared First-Slice Tile Needs

| Tile Category | Required Examples |
|---|---|
| Chess rug floor | light square, dark square, worn square, cracked square |
| Bedroom floor | wood plank, scuffed wood, shadowed wood |
| Paper damage | torn page, folded page, paper bridge |
| Chalk/crayon path | blue crayon line, chalk road, child mark |
| Low cover | toy block, fallen piece, book edge |
| Solid wall/block | toy block stack, furniture face, rug boundary |
| Reward/interact | glowing pickup base, weapon tile, safe marker |
| Hazard/telegraph support | danger overlay compatible floor variants |

## District Tile Kits

| District | Minimum Tile Kit |
|---|---|
| Toybox | plastic floor, toy track, ramp, toy wall, toy tunnel |
| Bookshelf | book spine, page floor, bookmark strip, paper gap, folded wall |
| Block Tower | block floor, block wall, ruler bridge, cracked block, gate |
| Dollhouse | wallpaper floor, carpet, tiny door, furniture edge, lamp glow |
| Under-Bed | blanket shadow, felt, dust, box edge, red rule crack |

## First-Chain Tile Palette

The first chain only needs:

```text
chess rug light/dark
broken chess rug
wood floor border
torn paper
fallen piece cover
weapon pickup highlight
simple solid boundary
danger overlay compatibility
```

## Completion Requirements

`ART.2` can be approved only if:

- required tile categories are finite and scoped,
- first-chain tile needs are separated from full-game tile needs,
- tiles support gameplay readability,
- and every tile category has a known gameplay or worldbuilding purpose.

## Cannot Approve If

- tile production starts without a category list,
- decorative tiles outnumber gameplay-readable tiles too early,
- first-chain tile needs are mixed with full-game polish,
- or danger telegraphs do not work on the chosen floors.
