# EN.2 Spec - Knight Behavior

**Status:** draft for owner review  
**Linked lane:** Enemy And Boss Design  
**Checklist gate:** `EN.2`

## Purpose

The Knight teaches that danger does not have to be adjacent. It pressures the
player through L-shaped threat reading, delayed commitment, and punish windows.

## Knight Combat Question

```text
Which L-shaped cell is about to become unsafe, and can I punish after the leap?
```

## Required Behavior

| Behavior | Requirement |
|---|---|
| Movement | Moves one cardinal cell at a time |
| Threat | Marks L-shaped target cells |
| Telegraph | Shows destination before damage |
| Commit | Leaps/strikes after clear delay |
| Recovery | Vulnerable after commit |
| Counterplay | Move adjacent, bait target, punish recovery |

## Boss Variant: Knight Captain

- Uses larger arena.
- Chains two or three marked leaps over phases.
- May use toy-track hazards.
- Teaches `Rule Step`.

## Completion Requirements

`EN.2` can be approved only if:

- L-shaped threat is visually readable,
- the Knight is different from Pawn without becoming unfair,
- the boss teaches Rule Step naturally,
- and recovery windows are accepted as the main counterplay.

## Cannot Approve If

- Knight feels like a random teleport attacker,
- L markers are unclear,
- or the first boss requires mechanics not taught in the Toybox district.
