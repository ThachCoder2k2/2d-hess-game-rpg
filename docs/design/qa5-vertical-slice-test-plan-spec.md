# QA.5 Spec - Vertical Slice Test Plan

**Status:** draft for owner review  
**Linked lane:** QA And Playtesting  
**Checklist gate:** `QA.5`

## Purpose

Define how the 10-15 minute vertical slice is tested end-to-end.

## Slice Test Path

```text
launch game
opening room
sword pickup
first combat
hub orientation
Toybox district
Knight boss
reward
return to hub
```

## Completion Requirements

`QA.5` can be approved only if the slice has a complete test route with pass/fail
criteria.

## Cannot Approve If

- the slice is only tested by jumping into scenes,
- boss/reward/return loop is unverified,
- or known blockers remain undocumented.
