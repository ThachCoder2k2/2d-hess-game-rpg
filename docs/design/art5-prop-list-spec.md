# ART.5 Spec - Prop List

**Status:** draft for owner review  
**Linked lane:** Art Direction  
**Checklist gate:** `ART.5`

## Purpose

Define props as gameplay/worldbuilding objects, not random decoration.

## Required Prop Categories

| Category | Examples | Gameplay Use |
|---|---|---|
| Chess remains | fallen pieces, cracked bases | story, cover, mood |
| Writing tools | pencil, crayon, eraser, ruler | weapons, skills, child help |
| Paper | torn page, bridge, fold, drawing | paths, locks, foreshadow |
| Toys | blocks, tracks, toy chest, doll furniture | district identity, cover |
| Bedroom furniture | bed, desk, bookshelf, chair | world structure |
| Light sources | desk lamp, moonlight, toy lamp | mood, route focus |

## Completion Requirements

`ART.5` can be approved only if:

- every prop category supports gameplay, story, or navigation,
- first-chain props are scoped,
- solid vs decorative props are distinguished,
- and props do not hide combat information.

## Cannot Approve If

- props are only filler,
- solid props are visually ambiguous,
- or prop density harms readability.
