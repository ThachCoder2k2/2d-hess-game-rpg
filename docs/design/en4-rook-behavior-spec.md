# EN.4 Spec - Rook Behavior

**Status:** draft for owner review  
**Linked lane:** Enemy And Boss Design  
**Checklist gate:** `EN.4`

## Purpose

The Rook teaches straight-line pressure, cover, and defensive timing.

## Rook Combat Question

```text
What can I put between myself and the charge line?
```

## Required Behavior

| Behavior | Requirement |
|---|---|
| Movement | Moves one cardinal cell at a time |
| Threat | Locks row or column |
| Telegraph | Centered line/arrow preview |
| Commit | Charges until blocked or until authored distance |
| Counterplay | Step aside, use cover, guard/parry |
| Arena role | Makes blocks and rulers meaningful |

## Boss Variant: Rook Warden

- Breaks weak blocks.
- Forces cover choice.
- Teaches `Eraser Guard`.

## Completion Requirements

`EN.4` can be approved only if:

- row/column threat is unmistakable,
- cover matters,
- Rook pressure is scary but answerable,
- and Eraser Guard has a clear role.

## Cannot Approve If

- Rook charges feel instant,
- cover rules are unclear,
- or straight-line attacks leave no response.
