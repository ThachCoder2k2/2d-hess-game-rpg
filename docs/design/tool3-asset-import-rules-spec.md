# TOOL.3 Spec - Asset Import Rules

**Status:** draft for owner review  
**Linked lane:** Tools And Editor Workflow  
**Checklist gate:** `TOOL.3`

## Purpose

Ensure sprites, tiles, audio, and references import consistently into Godot.

## Required Rules

- Pixel textures use nearest filtering.
- Assets use stable folders by purpose.
- Source/concept/reference images are separated from production sprites.
- Generated assets are not final unless accepted.
- Audio files route to intended buses.

## Completion Requirements

`TOOL.3` can be approved only if asset import settings and folder placement are
clear enough for both Codex and owner editing.

## Cannot Approve If

- assets blur from filtering,
- references are mistaken for production art,
- or import settings are inconsistent.
