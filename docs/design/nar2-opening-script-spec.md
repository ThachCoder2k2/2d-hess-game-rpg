# NAR.2 Spec - Opening Script

**Status:** draft for owner review  
**Linked lane:** Narrative And Worldbuilding  
**Checklist gate:** `NAR.2`

## Purpose

The opening must set stakes quickly and mostly visually.

## Required Opening Beats

```text
White army defeated.
White King falls.
Black pieces retreat.
Pawn remains.
Child notices.
Pawn wakes.
Player moves.
```

## Text Rule

Use minimal text. Prefer visual staging, room layout, and sound.

## Completion Requirements

`NAR.2` can be approved only if the opening can be understood without a long
cutscene.

## Cannot Approve If

- the player waits too long before moving,
- the story needs exposition to make sense,
- or the opening tone becomes comedy.
