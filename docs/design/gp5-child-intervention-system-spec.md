# GP.5 Spec - Child Intervention System

**Status:** draft for owner review  
**Linked lane:** Gameplay  
**Checklist gate:** `GP.5`

## Purpose

Child intervention turns the fourth-wall story into gameplay. The child changes
physical room state, but the pawn must still solve the fight.

## Intervention Rules

- The child changes terrain, routes, cover, or rules.
- The child does not directly delete enemies.
- Help is limited by meter, cooldown, room scripting, or boss phase.
- Child effects use crayon-blue, paper, block, hand, and eraser language.
- Bosses can temporarily disrupt help for drama.

## Proposed Interventions

| Intervention | Gameplay Use |
|---|---|
| Move Block | creates cover, blocks Rook lines, redirects enemies |
| Draw Chalk Path | creates temporary path over gaps or around threats |
| Place Paper Bridge | connects broken tiles |
| Erase Rule Mark | disables a marked hazard or lock briefly |
| Hold Ruler Gate | opens a shortcut or timed path |

## Completion Requirements

`GP.5` can be approved only if:

- child help is physical and readable,
- the pawn remains the hero,
- the first chain only foreshadows the system,
- the owner accepts limited-use help,
- and interventions can be authored per room.

## Cannot Approve If

- child help becomes a god power,
- child UI feels like generic magic,
- intervention solves boss phases automatically,
- or the child has no emotional presence.
