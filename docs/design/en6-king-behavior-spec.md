# EN.6 Spec - King Behavior

**Status:** draft for owner review  
**Linked lane:** Enemy And Boss Design  
**Checklist gate:** `EN.6`

## Purpose

The Black King is the final test of the rule-breaking theme. He represents the
rule system itself, not only a powerful piece.

## King Combat Question

```text
Which rule is being rewritten, and how do I stay free anyway?
```

## Required Behavior

| Behavior | Requirement |
|---|---|
| Base threat | Short-range one-cell King pressure |
| Rule engine | Activates old enemy patterns from arena edges |
| Corruption | Marks cells that temporarily obey old rules |
| Counterplay | Use all learned verbs, not stats |
| Final beat | Pawn and child cooperate but pawn lands victory |

## Phase Plan

```text
Phase 1: King is close and simple
Phase 2: old piece patterns return
Phase 3: rule engine corrupts selected cells
Phase 4: child help is blocked, then restored for final opening
```

## Completion Requirements

`EN.6` can be approved only if:

- final boss tests full-game mastery,
- rule corruption is visible and fair,
- child/pawn story resolves through play,
- and the ending preserves pawn identity.

## Cannot Approve If

- King is only a bigger health bar,
- final rules are invisible,
- or victory depends on a cutscene instead of player action.
