# NAR.6 Spec - Ending Script

**Status:** draft for owner review  
**Linked lane:** Narrative And Worldbuilding  
**Checklist gate:** `NAR.6`

## Purpose

The ending resolves the pawn's freedom and the child's companionship.

## Recommended Ending Image

```text
Morning light.
Quiet chessboard.
The pawn stands just outside the board.
A blue crayon line remains.
The child leaves the pawn there.
```

## Completion Requirements

`NAR.6` can be approved only if the ending preserves the pawn's identity and
emotionally resolves the child/pawn relationship.

## Cannot Approve If

- the ending is only victory text,
- promotion replaces freedom as the main meaning,
- or the child disappears from the resolution.
