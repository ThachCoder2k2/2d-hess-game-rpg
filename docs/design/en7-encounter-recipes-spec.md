# EN.7 Spec - Encounter Recipes

**Status:** draft for owner review  
**Linked lane:** Enemy And Boss Design  
**Checklist gate:** `EN.7`

## Purpose

Encounter recipes define safe, readable enemy combinations for rooms.

## Recipe Rules

- Teach with one enemy type.
- Test with one enemy type plus simple terrain.
- Twist with two pressure types, not three.
- Do not stack multiple unresolved telegraphs in early rooms.
- Common rooms should ask one main tactical question.

## Sample Recipes

| Recipe | Ingredients | Use |
|---|---|---|
| Pawn Intro | 1 Pawn Recruit | first combat |
| Pawn Pair | 2 Pawns, wide room | basic spacing test |
| Armed Pawn Lesson | 1 Pawn + visible weapon | weapon replacement teach |
| Knight Pressure | 1 Knight + 1 Pawn | L-threat plus approach pressure |
| Bishop Crossing | 1 Bishop + paper gap | lane crossing |
| Rook Cover | 1 Rook + block cover | straight-line defense |
| Queen Court | 1 Queen pattern + 2 pawns | late-game priority test |

## Completion Requirements

`EN.7` can be approved only if:

- recipes avoid unfair overlap,
- every recipe has a room purpose,
- early recipes stay simple,
- and boss districts escalate from their normal recipes.

## Cannot Approve If

- enemy combinations are chosen only by difficulty,
- rooms stack threats before teaching them,
- or recipes ignore room geometry.
