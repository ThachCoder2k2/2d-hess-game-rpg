# LD.4 Spec - Room Formula

**Status:** draft for owner review  
**Linked lane:** Level And World Design  
**Checklist gate:** `LD.4`

## Purpose

Every room should have a reason to exist. The game is short, so filler rooms are
not allowed.

## Room Formula

Each district should follow:

```text
Rest / reveal -> Teach -> Test -> Twist -> Boss or Reward -> Shortcut / return
```

## Room Types

| Type | Purpose |
|---|---|
| Story | mood or narrative beat |
| Teach | safe introduction of one idea |
| Test | real pressure using that idea |
| Twist | idea combined with prop, enemy, or route constraint |
| Reward | weapon, skill, shortcut, rescued piece, story beat |
| Boss | authored mastery test |
| Rest | breath, checkpoint, orientation |

## Completion Requirements

`LD.4` can be approved only if:

- every district uses teach-test-twist,
- rooms are categorized by purpose,
- boss rooms test previous rooms,
- and no room is allowed to exist only as hallway padding.

## Cannot Approve If

- rooms are planned only by aesthetics,
- combat rooms do not teach or test,
- or boss mechanics appear without preparation.
