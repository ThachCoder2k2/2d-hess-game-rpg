# ART.4 Spec - Character Sprite List

**Status:** draft for owner review  
**Linked lane:** Art Direction  
**Checklist gate:** `ART.4`

## Purpose

Define the finite sprite scope before producing character art.

## Required Sprite Families

| Sprite | Needed For |
|---|---|
| Hero pawn | full game, first chain |
| Black pawn recruit | first combat |
| Armed pawn variants | weapon escalation |
| Knight enemy | Toybox district |
| Knight Captain | first vertical-slice boss |
| Bishop | Bookshelf district |
| Rook | Block Tower district |
| Queen | Dollhouse boss |
| King | final boss |
| Child hand | intervention scenes |
| Fallen White King | opening focal prop/character |
| Fallen white pieces | opening and hub story dressing |

## Sprite Acceptance Rules

- Silhouette must read at gameplay zoom.
- Base/feet anchor must align to cell center.
- White and Black sides must be distinguishable without pure white/black.
- Bosses may be larger but must not hide active tiles.

## Completion Requirements

`ART.4` can be approved only if:

- first-chain sprite scope is separated from full-game sprite scope,
- boss sprites are listed but not required for the first build,
- and each sprite has a gameplay/story reason.

## Cannot Approve If

- sprite scope grows without purpose,
- silhouettes are unclear,
- or generated art cannot be animated cleanly.
