# QA.2 Spec - Room QA Checklist

**Status:** draft for owner review  
**Linked lane:** QA And Playtesting  
**Checklist gate:** `QA.2`

## Purpose

Define how every room is judged before acceptance.

## Room QA Checks

- Room opens in Godot.
- Player spawn is correct.
- Exits are readable and functional.
- Collision matches visuals.
- Enemy placement is fair.
- Objective/status text is correct.
- Art does not hide gameplay.
- Owner can identify room purpose.

## Completion Requirements

`QA.2` can be approved only if rooms have a repeatable acceptance checklist.

## Cannot Approve If

- room review is only visual,
- gameplay purpose is unclear,
- or exits/collision are untested.
