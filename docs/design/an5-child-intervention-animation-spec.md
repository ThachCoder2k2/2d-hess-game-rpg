# AN.5 Spec - Child Intervention Animation

**Status:** draft for owner review  
**Linked lane:** Animation  
**Checklist gate:** `AN.5`

## Purpose

Child intervention animation should feel like a real child physically helping
the pawn from outside the board.

## Required Intervention Motions

| Intervention | Motion |
|---|---|
| Move Block | hand enters, places/slides block |
| Draw Chalk Path | crayon draws path across cells |
| Paper Bridge | paper piece drops/folds into place |
| Erase Rule | eraser rubs out mark with dust |
| Ruler Gate | ruler presses or holds route open |

## Completion Requirements

`AN.5` can be approved only if:

- child actions are physical, not abstract magic,
- animations are slower/heavier than pawn combat,
- and child motion does not obscure active threats unfairly.

## Cannot Approve If

- child hand looks like a cursor,
- intervention timing feels instant/godlike,
- or child animation removes player agency.
