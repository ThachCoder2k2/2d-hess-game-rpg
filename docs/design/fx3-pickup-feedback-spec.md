# FX.3 Spec - Pickup Feedback

**Status:** draft for owner review  
**Linked lane:** VFX And Combat Feedback  
**Checklist gate:** `FX.3`

## Purpose

Pickups must be noticeable, understandable, and visually different from hazards.

## Required Feedback

- soft glow or outline,
- small idle motion,
- pickup sparkle/chime moment,
- HUD/status confirmation,
- distinct color from danger red.

## Completion Requirements

`FX.3` can be approved only if important pickups are visible at gameplay zoom
without looking like damage warnings.

## Cannot Approve If

- pickups blend into props,
- pickups use danger colors,
- or the player cannot tell what changed after pickup.
