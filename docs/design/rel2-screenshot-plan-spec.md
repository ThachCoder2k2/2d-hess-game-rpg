# REL.2 Spec - Screenshot Plan

**Status:** draft for owner review  
**Linked lane:** Release And Presentation  
**Checklist gate:** `REL.2`

## Purpose

Plan screenshots that honestly show the game.

## Required Screenshot Types

- opening mood,
- readable combat,
- child intervention,
- district identity,
- boss moment,
- hub/world orientation.

## Completion Requirements

`REL.2` can be approved only if screenshots show real gameplay and visual
identity.

## Cannot Approve If

- screenshots hide UI/combat,
- images are only concept art,
- or they do not explain the game's hook.
