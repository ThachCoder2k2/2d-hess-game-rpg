# UI.2 Spec - Tutorial Prompt Style

**Status:** draft for owner review  
**Linked lane:** UI, UX, And Tutorial  
**Checklist gate:** `UI.2`

## Purpose

Tutorial prompts should teach quickly without breaking pace or covering combat.

## Prompt Rules

- one idea per prompt,
- short wording,
- appears during safe moments,
- fades after use,
- does not repeat endlessly,
- can be paired with room objects/signs.

## Completion Requirements

`UI.2` can be approved only if prompts help first-time players without turning
the opening into text boxes.

## Cannot Approve If

- prompts explain multiple mechanics at once,
- prompts appear during danger,
- or the player needs chat/manual explanation to proceed.
