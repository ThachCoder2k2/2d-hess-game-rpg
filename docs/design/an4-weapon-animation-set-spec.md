# AN.4 Spec - Weapon Animation Set

**Status:** draft for owner review  
**Linked lane:** Animation  
**Checklist gate:** `AN.4`

## Weapon Animation Needs

| Weapon / Skill | Animation Identity |
|---|---|
| Sword | quick one-cell slash |
| Pencil Spear | longer straight thrust |
| Ruler Blade | wide front sweep |
| Eraser Guard | brace/parry with soft squash |
| Chalk Path | drawn line appears physically |
| Final Rule Break | rare, dramatic rule-tear motion |

## Completion Requirements

`AN.4` can be approved only if:

- each weapon has a unique silhouette/timing,
- animation communicates range,
- and attack timing can be matched to gameplay frames.

## Cannot Approve If

- weapons differ only by color,
- animation suggests wrong range,
- or skill effects hide enemies.
