# REL.3 Spec - Trailer Capture Plan

**Status:** draft for owner review  
**Linked lane:** Release And Presentation  
**Checklist gate:** `REL.3`

## Purpose

Define trailer beats before capture.

## Beat List

```text
White King falls
pawn wakes
sword pickup
first pawn combat
child changes room
Knight boss pressure
rule-breaking reward
bedroom world reveal
```

## Completion Requirements

`REL.3` can be approved only if the trailer plan communicates story, gameplay,
and visual identity quickly.

## Cannot Approve If

- trailer beats are only cinematic,
- combat readability is not shown,
- or the child-room hook is unclear.
