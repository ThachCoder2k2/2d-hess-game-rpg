# LD.6 Spec - District Layout Plans

**Status:** draft for owner review  
**Linked lane:** Level And World Design  
**Checklist gate:** `LD.6`

## Purpose

Define each major district as a compact loop with identity, mechanic, boss, and
reward.

## District Loop Template

```text
Entrance -> Teach -> Test -> Twist -> Boss -> Reward -> Shortcut back
```

## District Plans

| District | Rooms | Boss | Reward |
|---|---|---|---|
| Toybox Knight | 3 normal + boss | Knight Captain | Rule Step |
| Bookshelf Bishop | 3 normal + boss | Bishop Oracle | Chalk Path |
| Block Tower Rook | 3 normal + boss | Rook Warden | Eraser Guard |
| Dollhouse Queen | 3 normal + boss | Queen of Tricks | Black Castle access |
| Under-Bed King | 3 final rooms + boss | Black King | Ending |

## Completion Requirements

`LD.6` can be approved only if:

- every district has one mechanic focus,
- every district has a boss and reward,
- district length fits the 90-120 minute target,
- and shortcuts return the player to a sensible hub or route.

## Cannot Approve If

- districts become sprawling,
- mechanics repeat without escalation,
- bosses do not match district identity,
- or rewards do not affect future play.
