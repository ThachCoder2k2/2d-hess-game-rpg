# TOOL.4 Spec - Tile Editing Workflow

**Status:** draft for owner review  
**Linked lane:** Tools And Editor Workflow  
**Checklist gate:** `TOOL.4`

## Purpose

Make TileMap editing understandable and safe for the owner.

## Required Workflow Topics

- Which TileMap to edit.
- Which tiles are solid.
- How visual tiles affect collision.
- How to test painted walls.
- How to avoid breaking exits/spawns.
- How to review grid readability.

## Completion Requirements

`TOOL.4` can be approved only if the owner can change room tiles and understand
the gameplay consequences.

## Cannot Approve If

- tile painting can silently break collision,
- solid tiles are unclear,
- or exits/spawns are easy to cover accidentally.
