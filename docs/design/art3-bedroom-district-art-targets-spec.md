# ART.3 Spec - Bedroom District Art Targets

**Status:** draft for owner review  
**Linked lane:** Art Direction  
**Checklist gate:** `ART.3`

## Purpose

Define one clear art target per bedroom district so each area looks distinct
while still belonging to the same child-room chess war.

## District Art Sheets Required

| District | Required Sheet Contents |
|---|---|
| Chess Rug | board/rug tiles, fallen pieces, torn squares, white/black remains |
| Toybox | toy chest, tracks, ramps, toy walls, small toy clutter |
| Bookshelf | book spines, pages, bookmarks, paper bridges, folded paper |
| Block Tower | blocks, rulers, gates, breakable walls, straight-lane props |
| Dollhouse | wallpaper, tiny furniture, miniature doors, carpets, lamps |
| Under-Bed | blanket shadows, chess box, dust, red cracks, hidden toy debris |
| Desk/Child | paper, crayons, lamp glow, child marks, intervention props |

## Completion Requirements

`ART.3` can be approved only if:

- every district has a distinct material language,
- gameplay tiles are identified separately from decoration,
- each sheet supports its district mechanic,
- and the first-chain sheet is scoped before full-game polish.

## Cannot Approve If

- districts only differ by color,
- art targets do not support gameplay,
- or concept art cannot be translated into tiles/props.
