# FX.5 Spec - Boss Phase Feedback

**Status:** draft for owner review  
**Linked lane:** VFX And Combat Feedback  
**Checklist gate:** `FX.5`

## Purpose

Boss phase changes must be felt visually and mechanically, not only through HP.

## Required Phase Feedback

- boss animation change,
- arena lighting or prop change,
- new telegraph language introduced clearly,
- short safe beat before the new pattern becomes lethal,
- audio cue support.

## Completion Requirements

`FX.5` can be approved only if each boss phase change communicates what changed
and gives the player a fair first read.

## Cannot Approve If

- phase changes are invisible,
- new patterns begin instantly,
- or VFX overwhelms the arena.
