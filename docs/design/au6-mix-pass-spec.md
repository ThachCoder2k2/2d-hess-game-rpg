# AU.6 Spec - Mix Pass

**Status:** draft for owner review  
**Linked lane:** Audio  
**Checklist gate:** `AU.6`

## Purpose

Define audio priority so important information is always audible.

## Priority Order

```text
player damage
enemy telegraph
player attack impact
child intervention
pickup / reward
ambient SFX
music
```

## Completion Requirements

`AU.6` can be approved only if bus/volume priorities keep combat information
clear in busy rooms.

## Cannot Approve If

- music masks warnings,
- too many SFX stack at equal volume,
- or player damage lacks priority.
