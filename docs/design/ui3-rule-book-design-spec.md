# UI.3 Spec - Rule Book Design

**Status:** draft for owner review  
**Linked lane:** UI, UX, And Tutorial  
**Checklist gate:** `UI.3`

## Purpose

The Rule Book lets players review enemy rules and story flavor after learning
them in play.

## Required Behavior

- pages unlock after meeting enemies,
- locked pages read as unread/unknown,
- each page shows original chess rule and broken-world amendment,
- UI pauses or safely interrupts gameplay,
- text stays concise.

## Completion Requirements

`UI.3` can be approved only if the Rule Book supports learning without becoming
required homework.

## Cannot Approve If

- pages reveal enemies too early,
- text is long and mandatory,
- or opening it causes gameplay confusion.
