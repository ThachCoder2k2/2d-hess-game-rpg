# GP.7 Spec - Progression Pacing

**Status:** draft for owner review  
**Linked lane:** Gameplay  
**Checklist gate:** `GP.7`

## Purpose

Define the 90-120 minute unlock rhythm so the game escalates without becoming
too complex.

## Proposed Pacing

| Time | Content | Unlock / Mastery |
|---|---|---|
| 0-10 min | opening + sword | movement, turn, sword |
| 10-25 min | first battlefield + hub | pawn reading, Pencil optional |
| 25-45 min | Toybox / Knight | Rule Step |
| 45-65 min | Bookshelf / Bishop | Chalk Path |
| 65-85 min | Block Tower / Rook | Eraser Guard |
| 85-105 min | Dollhouse / Queen | mastery under disruption |
| 105-120 min | Under-Bed / King | Final Rule Break |

## Completion Requirements

`GP.7` can be approved only if:

- unlocks are spaced across the whole game,
- every unlock has a teach/test room,
- the first vertical slice ends at a satisfying unlock,
- and the owner agrees this scope fits a short game.

## Cannot Approve If

- unlocks arrive too quickly to learn,
- late game adds too many new verbs,
- or the game requires RPG/stat grinding to feel complete.
