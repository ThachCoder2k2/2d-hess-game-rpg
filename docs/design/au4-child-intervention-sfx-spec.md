# AU.4 Spec - Child Intervention SFX

**Status:** draft for owner review  
**Linked lane:** Audio  
**Checklist gate:** `AU.4`

## Purpose

Child intervention sounds must feel physical, gentle, and larger than the chess
pieces.

## Required Material Sounds

- crayon scratch,
- paper fold/drop,
- block placement,
- eraser rub,
- hand movement/cloth air,
- soft room-light shift.

## Completion Requirements

`AU.4` can be approved only if child actions sound like real objects entering
the board, not abstract magic spells.

## Cannot Approve If

- child sounds feel like UI clicks,
- intervention audio is too explosive,
- or material identity is unclear.
