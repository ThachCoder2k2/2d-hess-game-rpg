# UI.5 Spec - Input Remap And Controller Plan

**Status:** draft for owner review  
**Linked lane:** UI, UX, And Tutorial  
**Checklist gate:** `UI.5`

## Purpose

Controls must support fast grid combat on keyboard and controller.

## Required Actions

- move,
- turn without moving,
- attack,
- skill,
- interact,
- child help,
- focus,
- pause,
- rule book.

## Completion Requirements

`UI.5` can be approved only if every gameplay verb has a clear keyboard and
controller mapping plan.

## Cannot Approve If

- turn/attack/skill conflict ergonomically,
- controller support is undefined,
- or controls cannot be explained in one small panel.
