# QA.3 Spec - Combat Feel Tests

**Status:** draft for owner review  
**Linked lane:** QA And Playtesting  
**Checklist gate:** `QA.3`

## Purpose

Combat feel requires play judgment, not only passing automated tests.

## Required Feel Checks

- movement responsiveness,
- hold movement comfort,
- turn usefulness,
- sword timing,
- telegraph reaction time,
- hit feedback satisfaction,
- enemy recovery punishability.

## Completion Requirements

`QA.3` can be approved only if combat feel feedback is recorded and acted on.

## Cannot Approve If

- tests pass but owner says combat feels wrong,
- timing changes are not tracked,
- or feedback lacks room/context.
