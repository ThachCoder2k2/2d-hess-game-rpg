# FX.4 Spec - Defeat Feedback

**Status:** draft for owner review  
**Linked lane:** VFX And Combat Feedback  
**Checklist gate:** `FX.4`

## Purpose

Defeat feedback should make enemies clearly leave combat while preserving the
toy/chess tone.

## Required Defeat Language

- piece tips, cracks, or slumps,
- small dust/chip effect,
- no gore,
- telegraph cleanup,
- clear removal or inactive state.

## Completion Requirements

`FX.4` can be approved only if defeated enemies stop reading as active threats
and the effect fits chess/toy materials.

## Cannot Approve If

- defeated enemies look alive,
- gore breaks tone,
- or defeat effects leave stale telegraphs.
