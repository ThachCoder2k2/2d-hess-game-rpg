# UI.6 Spec - Accessibility Options

**Status:** draft for owner review  
**Linked lane:** UI, UX, And Tutorial  
**Checklist gate:** `UI.6`

## Purpose

Accessibility options preserve the game's readability and comfort.

## Proposed Options

- reduce screen shake,
- focus/telegraph emphasis,
- text speed,
- audio sliders,
- high-contrast danger mode,
- hold-to-repeat tuning later if needed.

## Completion Requirements

`UI.6` can be approved only if the planned options address motion, visibility,
text, and audio comfort.

## Cannot Approve If

- color is the only threat cue,
- shake cannot be reduced,
- or text/audio comfort is ignored.
