# AU.3 Spec - Enemy Telegraph SFX

**Status:** draft for owner review  
**Linked lane:** Audio  
**Checklist gate:** `AU.3`

## Purpose

Enemy warning sounds support reaction timing and help distinguish threat families.

## Required Warning Families

| Threat | Sound Direction |
|---|---|
| Pawn | short scrape/tick |
| Knight | rising hop/landing cue |
| Bishop | paper shimmer/diagonal hum |
| Rook | ruler slide/wooden charge |
| Queen | layered royal cue, restrained |
| King | rule crack/glass-paper tension |

## Completion Requirements

`AU.3` can be approved only if warning sounds arrive before danger and remain
audible over music.

## Cannot Approve If

- warning sounds are decorative,
- all enemies use the same cue,
- or audio warnings play after damage.
