# NAR.5 Spec - Boss Dialogue And Behavior Beats

**Status:** draft for owner review  
**Linked lane:** Narrative And Worldbuilding  
**Checklist gate:** `NAR.5`

## Purpose

Bosses should express character through behavior first and dialogue second.

## Boss Beat Rules

- one short intro beat,
- one behavior that expresses personality,
- one phase-change beat,
- one defeat beat,
- no long speeches during active combat.

## Completion Requirements

`NAR.5` can be approved only if every boss has a distinct identity and gameplay
expression.

## Cannot Approve If

- bosses speak too much,
- identity exists only in text,
- or phase changes lack story meaning.
