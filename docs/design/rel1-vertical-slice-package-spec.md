# REL.1 Spec - Vertical Slice Package

**Status:** draft for owner review  
**Linked lane:** Release And Presentation  
**Checklist gate:** `REL.1`

## Purpose

Define what must be included before sharing a playable demo.

## Package Contents

- playable build,
- controls note,
- known issues,
- target playtime,
- feedback questions,
- version/date.

## Completion Requirements

`REL.1` can be approved only if the demo can be played outside the editor and
understood by a tester.

## Cannot Approve If

- the slice only runs in Godot editor,
- controls are undocumented,
- or blocker bugs are hidden.
