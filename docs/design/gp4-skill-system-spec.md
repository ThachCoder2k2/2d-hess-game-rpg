# GP.4 Spec - Skill System

**Status:** draft for owner review  
**Linked lane:** Gameplay  
**Checklist gate:** `GP.4`

## Purpose

Skills are new tactical verbs. They should change what the player can decide,
not simply increase damage.

## Skill Philosophy

```text
movement stays one-cell and readable
skills create situational answers
each skill is taught by a room or boss
skills do not replace sword fundamentals
```

## Proposed Skill Set

| Skill | Role | Unlock |
|---|---|---|
| Pencil Thrust | two-cell straight poke with recovery | early chess rug / first weapon beat |
| Rule Step | short emergency reposition / dodge | Knight boss |
| Chalk Path | child-assisted temporary path | Bishop boss |
| Eraser Guard | defensive/parry answer to straight pressure | Rook boss |
| Final Rule Break | story climax, limited scripted use | Queen/King finale |

## Completion Requirements

`GP.4` can be approved only if:

- each skill changes a tactical decision,
- each skill has a teaching moment,
- skills do not make basic movement irrelevant,
- cooldown/cost philosophy is accepted,
- and the owner agrees the proposed set is enough for a 90-120 minute game.

## Cannot Approve If

- skills become generic upgrades,
- too many skills are introduced too early,
- the player can ignore room/enemy rules by spamming skills,
- or the first vertical slice needs more than Sword, Pencil, and Rule Step.
