# LD.7 Spec - Shortcuts And Locks

**Status:** draft for owner review  
**Linked lane:** Level And World Design  
**Checklist gate:** `LD.7`

## Purpose

Locks and shortcuts should make the bedroom feel connected without making the
player lost.

## Lock Types

| Lock | Example |
|---|---|
| Physical toy block | child moves later |
| Paper gap | Chalk Path or paper bridge |
| Ruler gate | held open after Rook/child interaction |
| Story seal | Queen/King progression lock |
| One-way shortcut | opened from the far side |

## Rules

- Locked routes should be visible before they open.
- The player should understand why a path is blocked.
- Shortcuts should reduce repeat travel.
- Locks should be tied to skill, story, or district completion.

## Completion Requirements

`LD.7` can be approved only if:

- lock language is readable,
- shortcuts reward exploration/progress,
- first hub locked routes are planned,
- and locks do not require arbitrary keys without context.

## Cannot Approve If

- locked routes look like normal exits,
- shortcuts do not save meaningful travel,
- or players need external notes to remember what opens what.
