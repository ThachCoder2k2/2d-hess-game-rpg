# NAR.4 Spec - District Story Beats

**Status:** draft for owner review  
**Linked lane:** Narrative And Worldbuilding  
**Checklist gate:** `NAR.4`

## Purpose

Every district should advance the theme, not only add enemies.

## Story Beats

| District | Beat |
|---|---|
| Toybox | pawn learns status is not strength |
| Bookshelf | written rules can be redrawn |
| Block Tower | walls and lines can be resisted |
| Dollhouse | control and performance are fragile |
| Under-Bed | the rule system is confronted directly |

## Completion Requirements

`NAR.4` can be approved only if each district has one clear story/theme beat.

## Cannot Approve If

- districts are only visual themes,
- story repeats the same beat,
- or bosses lack connection to district theme.
