# REL.5 Spec - Final Build Checklist

**Status:** draft for owner review  
**Linked lane:** Release And Presentation  
**Checklist gate:** `REL.5`

## Purpose

Define the minimum release-candidate checks.

## Build Checklist

- clean project launch,
- no blocker bugs,
- controls documented,
- audio levels checked,
- settings work,
- save/restart behavior works,
- target platform export tested,
- known issues listed.

## Completion Requirements

`REL.5` can be approved only if release readiness is judged by a written
checklist, not memory.

## Cannot Approve If

- export path is untested,
- known blockers remain,
- or QA notes are missing.
