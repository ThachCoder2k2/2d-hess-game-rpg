# EN.3 Spec - Bishop Behavior

**Status:** draft for owner review  
**Linked lane:** Enemy And Boss Design  
**Checklist gate:** `EN.3`

## Purpose

The Bishop controls diagonal space and teaches the player to cross lanes,
respect line-of-sight, and use child-created paths.

## Bishop Combat Question

```text
How do I cross or interrupt the diagonal lane safely?
```

## Required Behavior

| Behavior | Requirement |
|---|---|
| Movement | Moves one cardinal cell at a time |
| Threat | Diagonal lane or beam |
| Telegraph | Long diagonal preview before impact |
| Counterplay | Step across timing gap, use cover, use Chalk Path |
| Role | Space controller, not chaser |

## Boss Variant: Bishop Oracle

- Uses diagonal beams.
- Uses paper/mirror reflectors only after teaching.
- Tests Chalk Path in phase three.

## Completion Requirements

`EN.3` can be approved only if:

- diagonal lanes are readable,
- the Bishop does not clutter the whole board,
- the Bookshelf district teaches before testing,
- and Chalk Path has a real reason to exist.

## Cannot Approve If

- diagonal attacks become screen-filling noise,
- Bishop behaves like a Pawn with longer range,
- or safe crossing logic is not visible.
