# UI.4 Spec - Pause And Settings

**Status:** draft for owner review  
**Linked lane:** UI, UX, And Tutorial  
**Checklist gate:** `UI.4`

## Purpose

Basic pause/settings make the game usable during development and playtesting.

## Required Settings

- resume,
- restart room,
- audio volumes,
- controls reference,
- quit to desktop/menu,
- screen shake toggle or slider later.

## Completion Requirements

`UI.4` can be approved only if testers can pause, adjust basic comfort settings,
and restart without developer help.

## Cannot Approve If

- pause hides important state permanently,
- settings are inaccessible,
- or testers need engine controls to recover.
