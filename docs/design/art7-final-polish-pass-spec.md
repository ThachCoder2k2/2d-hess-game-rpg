# ART.7 Spec - Final Polish Pass

**Status:** draft for owner review  
**Linked lane:** Art Direction  
**Checklist gate:** `ART.7`

## Purpose

Define what "polished enough" means for a vertical slice.

## Polish Scope

For the first slice, polish applies to:

- first-chain rooms,
- Toybox district if included,
- hero pawn,
- pawn/knight enemies,
- first boss,
- HUD readability,
- core VFX/audio feedback.

## Completion Requirements

`ART.7` can be approved only if:

- placeholder-looking assets are removed from the slice path,
- visual language is consistent,
- no art pass breaks readability,
- and screenshots represent the intended game honestly.

## Cannot Approve If

- polish means adding clutter,
- core gameplay assets still read as debug placeholders,
- or final visuals only work in one room.
