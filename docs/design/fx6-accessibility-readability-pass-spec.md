# FX.6 Spec - Accessibility And Readability Pass

**Status:** draft for owner review  
**Linked lane:** VFX And Combat Feedback  
**Checklist gate:** `FX.6`

## Purpose

Ensure threat information remains readable for more players and across busy
rooms.

## Required Checks

- grayscale screenshot check,
- reduced camera shake option,
- clear Focus mode behavior,
- danger colors contrasted on light/dark tiles,
- no critical information communicated by color only.

## Completion Requirements

`FX.6` can be approved only if threat readability survives color, motion, and
busy-room stress tests.

## Cannot Approve If

- color is the only danger cue,
- screen shake hides threats,
- or Focus mode makes the game unreadable in another way.
