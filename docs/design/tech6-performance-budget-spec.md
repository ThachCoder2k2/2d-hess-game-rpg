# TECH.6 Spec - Performance Budget

**Status:** draft for owner review  
**Linked lane:** Technical Architecture  
**Checklist gate:** `TECH.6`

## Purpose

Set simple performance expectations before rooms become visually busy.

## Target Budget

- Stable 60 FPS target on the development machine.
- Internal canvas stays 640x360.
- Combat rooms keep active enemies limited.
- VFX disappear quickly.
- Debug overlays are optional/toggleable.

## Completion Requirements

`TECH.6` can be approved only if rooms, VFX, AI, and UI have agreed limits that
protect readability and framerate.

## Cannot Approve If

- visual polish tanks gameplay responsiveness,
- debug tools always run at full cost,
- or boss rooms exceed readable object density.
